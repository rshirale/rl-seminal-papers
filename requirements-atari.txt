# The Atari packages for the Chapter 3 Atari training script, on their own.
# requirements-deep.txt (make install-full) already includes every line below,
# so that the Chapter 3 Atari tests run in CI; this file exists for a setup
# that brings torch some other way and wants only the Atari stack. Atari
# packages can need native libraries (SDL2, a C++ toolchain) on some systems.
#
# The gymnasium bound must match requirements.txt and requirements-deep.txt --
# when the ranges disagree, installing one file after the other silently
# downgrades gymnasium. >=1.0 is also what makes gym.register_envs() available,
# which train_atari.py needs to register the ALE environments.
gymnasium[atari]>=1.0,<2.0
opencv-python>=4.5.0

# ale-py (pulled in by the [atari] extra) dropped x86_64 macOS wheels after
# 0.11.0. Without this cap, pip falls back to a source build that fails on
# Intel Macs. Every other platform tracks the latest release.
ale-py<=0.11.0; sys_platform == "darwin" and platform_machine == "x86_64"
