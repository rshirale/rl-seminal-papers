Papers → Code

Every equation in the book maps directly to a line of Python. No black boxes.

📄 Sutton (1988) — TD(0) Update
V(Sₜ) ← V(Sₜ) + α [ Rₜ₊₁ + γ V(Sₜ₊₁) − V(Sₜ) ]
💻 Python Implementation
# Bootstrapped TD error
td_error = (reward + gamma * V[next_s]) - V[s]
V[s] += alpha * td_error
