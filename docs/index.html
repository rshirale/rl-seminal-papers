Sutton (1988) — TD(0) Update Rule

V(St) ← V(St) + α [Rt+1 + γ·V(St+1) − V(St)]

Temporal-difference error drives value updates — no model, no Monte Carlo rollout.

Python · Chapter 2 
# Bootstrapped TD error
td_error = (
    reward + gamma * V[next_s]
) - V[s]

V[s] += alpha * td_error

2

Install dependencies

make install  (Foundations — lightweight)  |  make install-full  (Full Deep RL stack)
3

Run an experiment

make run-ch2-cliff  — Q-Learning vs SARSA on Cliff Walking
