Sutton (1988) — TD(0) Update Rule

V(St) ← V(St) + α [Rt+1 + γ·V(St+1) − V(St)]

Temporal-difference error drives value updates — no model, no Monte Carlo rollout.

Quick Start

Running in minutes

Clone the repo and run an available chapter experiment locally or open one of the available notebooks in Colab.

1

Clone the repository

git clone https://github.com/rshirale/rl-seminal-papers.git
2

Install dependencies

make install
foundation stack for Chapters 1–2
make install-full
PyTorch stack for Chapters 3–6
make install-llm
transformers and peft, for the Chapter 7 trainer only; its reward function and group-size analysis need neither
make install-atari
optional; only for the Chapter 3 Atari run
make install-test
then make test for the fast suite, or make test-all to execute the notebooks
make doctor
if anything fails, this reports your interpreter, platform, and package status
3

Run an experiment

make run-ch1
the minimal agent-environment loop on CartPole
make run-ch2-gridworld
TD(0) value estimation on the 4×3 Grid World
make run-ch2-cliff
Q-Learning vs SARSA on Cliff Walking
make run-ch3-cartpole
DQN on CartPole-v1 (~3 min on CPU)
make run-ch3-atari
DQN on Atari Pong; needs make install-atari
make run-ch3-ablation
ablate DQN’s replay buffer and target network (the paper’s own ablation, on CartPole); ~20 min on a CPU
make run-ch4-pendulum
DDPG on Pendulum-v1 (~3 min on CPU)
make run-ch4-ablation
ablate DDPG’s target networks (the chapter’s figure 4.10); nine training runs, ~92 min on an 8-core CPU
make run-ch5-pendulum
PPO on Pendulum-v1 (~4 min on CPU)
make run-ch5-ablation
ablate PPO’s clipped objective (the chapter’s figure 5.9)
make run-ch5-seeding
what the seed alone is worth, before trusting any comparison
make run-ch6-pendulum
SAC on Pendulum-v1 (~10 min on CPU); seed 42 reproduces the chapter’s transcript
make run-ch6-ablation
ablate SAC’s entropy bonus (the chapter’s exercise 1); six training runs, ~30 min on a CPU
make run-ch6-seeding
SAC’s seed-to-seed spread — the threshold every table in the chapter should be read against
make run-ch7-reward
what GRPO’s rule-based reward pays or charges for each kind of model output; instant, and needs nothing installed
make run-ch7-group-size
how often a group carries no gradient at all (the chapter’s exercise 3); also instant
make run-ch7-train
GRPO on strict JSON schema adherence — a base language model, a rule, and no critic; ~36 min on a CPU, and needs make install-llm

Chapter 6’s three exercises — the entropy ablation, fixed vs learned temperature, and the reward-scale run — take an hour or more between them. They also run on GitHub’s machines: Actions → Chapter 6 SAC ablations → Run workflow runs all three in parallel and attaches the tables and figures as artifacts. Absolute numbers from a CI runner will not match a local run, but every variant inside one run shares a machine, so the comparison holds.
