Papers → Code

Every equation in the book maps directly to a line of Python. No black boxes.

Sutton (1988) — TD(0) Update
V(Sₜ) ← V(Sₜ) + α [ Rₜ₊₁ + γ V(Sₜ₊₁) − V(Sₜ) ]
Python Implementation
# Bootstrapped TD error
td_error = (reward + gamma * V[next_s]) - V[s]
V[s] += alpha * td_error

Quick Start

Clone the repo and run any chapter experiment in minutes.

1

Clone the repository

git clone https://github.com/rshirale/rl-seminal-papers.git
2

Install dependencies

make install  (Foundations — lightweight)  |  make install-full  (Full Deep RL stack)
3

Run an experiment

make run-ch2-cliff  — Q-Learning vs SARSA on Cliff Walking
4

Or open in Colab — no setup required
